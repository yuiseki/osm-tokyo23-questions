# Nouns for the tags this collection does not have
#
# One block per OSM tag that the synthesised Tokyo questions use, that
# data/seeds/category does not have, and that has questions with an answer in
# tokyo23-260831.osm.pbf. Sorted by how often three models failed to name the
# tag while writing SQL for it, so the ones at the top are the ones worth
# having.
#
# Write the noun a person would use on the two lines. Nothing here is filled
# in: the candidate is a candidate. What fills a slot in this collection is
# written or chosen by a person, and a label copied out of Wikidata by a
# script has been neither until someone reads it.
#
# candidate  the English label of the Wikidata item whose P1282 is this tag.
#            Usually the noun wanted, sometimes narrower than the OSM tag.
# osm        what the OSM wiki says the tag means, through osm-tag-corpus.
# wikidata   what Wikidata says its item means. Where the two disagree, the
#            candidate is describing something else.
# generator  the noun the synthesiser used, which is the tag value with an s.
#
# Leave both lines empty to skip a tag. Some tags should be skipped: where the
# features under one tag are unlike each other, no noun names them, and forcing
# one writes a question that does not mean what it counts.
